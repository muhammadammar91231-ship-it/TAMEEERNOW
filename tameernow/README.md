# TameerNow

Next.js 14 (App Router) + Tailwind CSS + Lucide React website for TameerNow home renovation services.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build for production

```bash
npm run build
npm start
```

## Deploy

Push to GitHub and import the repo on Vercel (zero config).

## Structure

- `app/` — pages (home, about, services, contact) and root layout
- `components/` — Navbar, Footer, BeforeAfterSlider, ConsultationForm, FloatingWhatsApp
- `next.config.mjs` — allows Unsplash images via `next/image`
